# rDM Changelog

All notable changes to rDM are documented in this file.

## v1.0.0

Initial public release of rDM.

### Features

* **Download Controls.** Pause and resume supported downloads, retry interrupted downloads, set speed limits, and choose where to save files.
* **Dashboard and Download History.** See download speeds and time remaining, and find completed downloads in a calendar.
* **Chrome and Firefox Integration.** Send downloads to rDM from your browser and choose video or audio when downloading from YouTube.
* **Appearance.** Switch between light and dark themes and choose an accent color.
* **Windows and Linux Editions.** Install rDM on Windows or Linux, or use the portable edition on Windows.
